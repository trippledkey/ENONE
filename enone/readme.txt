Моя дипломная работа "ENONE - онлайн-школа для изучения английского языка"
В дирректория сайта выглядит так :
enone/
├── admin/
│   ├── add_course.php
│   ├── add_teacher.php
│   ├── config.php
│   ├── delete_course.php
│   ├── delete_teacher.php
│   ├── edit_course.php
│   ├── edit_teacher.php
│   ├── functions.php
│   ├── index.php
│   ├── login.php
│   ├── manage_courses.php
│   ├── manage_teachers.php
├── css/
│   ├── style.css
├── images/
│   ├──(фотографии)
├── js   
    ├── script.js
├── about.php - файл с информацией о школе (будет доработан)
├── config.php - файл с параметрами подключения к базе данных
├── contact.php - файл с обратной связью для пользователей
├── courses.php - файл с информацией о курсах (цены будут назначены путем мониторинга цен у конкурентов, выведена средняя цена, которая не приведет к убыткам для "бизнеса", но привлекательная для пользователей)
├── enone.sql - (файл ДБ)
├── index.php - главная страница сайта
├── login.php - файл с формой авторизации
├── profile.php - профиль пользователя (будет доработан)
├── register.php - файл с формой регистрации
├── teachers.php - файл с информацией о преподавателях
Папка админ подразумевает вход в админку сайта, после чего можно добавить курсы и преподавателей, а так же удалять их из базы данных.
(название файла показывает на что способна админка)

Стек сайта очень прост - HTML,CSS, JS(файл пока пустует), PHP и MySQL
Для работы с БД я использовал PHPMyAdmin и программу XAMPP.
